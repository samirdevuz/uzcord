# UzCord Music System Documentation

## Overview
UzCord's music system is built using `@discordjs/voice` for audio playback in Discord voice channels.

## Commands
- `/music play url:<url_or_name>`: Joins voice channel and queues track.
- `/music pause`: Pauses current playback.
- `/music resume`: Resumes playback.
- `/music skip`: Skips to the next track.
- `/music stop`: Stops playback and clears queue.
- `/music queue`: Views current queue.
- `/music nowplaying`: Displays currently playing track.
- `/music leave`: Leaves the voice channel.
