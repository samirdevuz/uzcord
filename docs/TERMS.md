# Foydalanish shartlari — UzCord

**Oxirgi yangilanish:** 2026-yil 20-sentabr

UzCord botidan foydalanish orqali siz quyidagi shartlarga rozilik bildirasiz.

## 1. Foydalanish

Bot Discord serverlarini moderatsiya qilish uchun mo'ljallangan.
Uni serverga qo'shish orqali siz ushbu shartlarni va
[Maxfiylik siyosatini](PRIVACY.md) qabul qilasiz.

## 2. Taqiqlanadi

- Botdan Discord [Foydalanish shartlari](https://discord.com/terms) yoki
  [Jamoa qoidalari](https://discord.com/guidelines) ga zid maqsadlarda foydalanish.
- Botga spam yuborish, uni ataylab ortiqcha yuklash yoki xizmatini buzishga urinish.
- Botdan boshqa foydalanuvchilarni ta'qib qilish, qo'rqitish yoki zarar yetkazish uchun foydalanish.
- Botning zaifliklarini yomon niyatda qidirish yoki ulardan foydalanish.

## 3. Mas'uliyat

Bot "qanday bo'lsa shundayligicha" taqdim etiladi. Muallif quyidagilar uchun
javobgar emas:

- Botning noto'g'ri sozlanishi natijasida yuzaga kelgan zarar.
- Ma'lumotlar yo'qolishi, xizmatning vaqtincha ishlamasligi.
- Moderatorlarning bot orqali qilgan xatolari.

Server egasi botni to'g'ri sozlash va unga berilgan ruxsatlar uchun to'liq javobgar.

## 4. Xizmatni to'xtatish

Ushbu shartlar buzilgan taqdirda botdan foydalanish istalgan vaqtda,
ogohlantirishsiz to'xtatilishi mumkin.

## 5. Ochiq kod

UzCord MIT litsenziyasi ostida tarqatiladi. Kodni o'zingizda ishga tushirishingiz,
o'zgartirishingiz va tarqatishingiz mumkin. Manba:
[github.com/samirdevuz/uzcord](https://github.com/samirdevuz/uzcord)

## 6. O'zgarishlar

Shartlar o'zgarishi mumkin. Davom etib foydalanish yangi shartlarni qabul qilish deb hisoblanadi.
